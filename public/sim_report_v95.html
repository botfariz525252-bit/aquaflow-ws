🏫 Penjelasan Awam — Semua Yang Penting

🔄 Kenapa baud rate penting?

Baud rate = kecepatan kirim data. 9600 baud = 9600 bit/detik.
Satu karakter = 10 bit → 9600/10 = 960 karakter/detik.
UNO kirim 72 karakter → butuh 72/960 = 75ms blocking!
Selama 75ms itu: loop() berhenti total. Timer 100ms jadi 175ms. dt jadi 175ms tapi di-clamp ke 150ms.
pvRate pakai dt 150ms tapi actual 175ms → pvRate 17% salah.
Naik ke 115200 baud → 72 karakter = 6ms. Problem solved.

⚙️ Kenapa PID butuh warmup?

EMA (Exponential Moving Average) = filter yang butuh beberapa sample untuk "settle".
Sample pertama: EMA = nilai mentah (bisa spike dari sonar).
Kalau PID langsung aktif dengan EMA belum stabil: D-term hitung perubahan dari nilai spike → output spike → pompa nyala tiba-tiba.
Fix: tunggu 15 iterasi (1.5 detik) dulu. Kecil banget di real-world tapi penting untuk safety.

🐛 Bug terbodoh: anti-droop yang tidak pernah kerja

Kode v9.4:
e = 0.0f; // e di-nol-kan karena dalam deadband
...
pidInteg += Ki * e * dt * 0.05f; // ← e=0, jadi ini += 0 selalu!
Hasilnya: anti-droop tidak pernah menghasilkan apapun. Drain konstan tetap tidak ter-kompensasi.
Fix v9.5: simpan e_raw sebelum di-nol, pakai e_raw untuk anti-droop.

📐 Steady State Output = 20% — kenapa?

SS output = drain_rate / fill_rate_max = 0.1%/s ÷ 0.5%/s = 20%
Ini fisika murni. Apapun SP-nya (30%, 50%, 70%), kalau level sudah stabil, pompa harus nyala 20% waktu.
Kalau pompa nyala lebih → level naik terus. Kurang → level turun terus.
PID/autotune cuma ngatur: seberapa cepat dan seberapa mulus sampainya. Tidak bisa ubah 20% ini.
